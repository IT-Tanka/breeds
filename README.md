# Pet Breed Explorer

A web app for exploring dog and cat breeds — built as a technical assignment demonstrating Next.js, TypeScript, and Tailwind CSS.

## Overview
The homepage shows random cat and dog breeds as cards (image + name). Clicking a card opens a breed detail page with full information and an image gallery.

## Features
- Random breed listing on the homepage, pulled from two external APIs
- Detail page per breed with description and a photo gallery
- Responsive, clean UI styled with Tailwind CSS

## Tech Stack
- Next.js (Pages Router) — routing and rendering
- TypeScript — type safety
- Tailwind CSS — styling
- React Hooks (`useState`, `useEffect`) — data fetching and local state
- **The Dog API** & **The Cat API** — breed data and images

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Assignment Brief
Build a web app with Next.js, TypeScript, and Tailwind CSS. The homepage displays a list of random cat and dog breeds in card format (image + name); clicking a card navigates to a breed detail page with full information and a gallery of images for that breed.
